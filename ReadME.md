# 🔍 Sorting Analyser

**Sorting Analyser** is a web-based tool that helps you visualize, analyze, and compare various sorting algorithms in real-time.

## 🚀 Features

- 🎞️ Real-time visualization of sorting steps
- 🔁 Supports multiple sorting algorithms:
  - Bubble Sort
  - Selection Sort
  - Insertion Sort
  - Merge Sort
  - Quick Sort
  - Heap Sort
- ⚙️ Adjustable array size and sorting speed
- 📊 Performance metrics (comparisons, swaps, time)
- 🎨 Clean and interactive UI for enhanced learning
